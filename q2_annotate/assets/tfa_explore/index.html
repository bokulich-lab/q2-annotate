The 100 samples with the highest loads are shown; the group comparison uses every sample. Colors match the groups labeled in the panel on the left.

TFA (Taxonomic Functional Attribution) load estimates how much of a function is attributed to a taxon in a sample. For each contig assigned to that taxon, the function copy count is multiplied by the contig's abundance in that sample. These contributions are summed across the taxon's contigs. Unclassified taxa are hidden by default; toggle the "Show unclassified taxa" checkbox to include them.

Heatmap: Each cell shows the sum, mean, or median load for one taxon–function pair across all samples, including zeros. At a selected taxonomy level, taxa sharing a lineage are summed within each sample before this summary is calculated. Top links are ranked before applying the Taxon and Function dropdown selections. These selections narrow the axes; limits that would hide either selection are disabled. All links keeps selections available beyond the finite cutoffs. All intersections between the remaining taxa and functions are shown, including links below the cutoff. Dots in the upper-right corners mark the top N links; white cells have a zero summary and gray cells indicate a pair absent from the TFA table. Hover for details; click an existing pair to inspect its sample loads. Labels use the last classified rank when deeper ranks are missing.

Bottom plots: Each sample contributes one value: the sum of loads for all taxon–function pairs matching the current filters. Selecting one function and all taxa therefore sums that function's load across the displayed taxa within each sample. Each box shows the distribution of these per-sample values within a metadata group; each bar shows one sample's value. Zero loads are included. Metadata only groups samples in these plots; it does not change the loads or the heatmap summaries. Samples with missing metadata form a separate group.

Box plots (Tukey): The line inside each box marks the median. The box spans the 25th to 75th percentiles (Q1–Q3), and the interquartile range is IQR = Q3 − Q1. Whiskers extend to the smallest and largest observed sample values within the range Q1 − 1.5 × IQR to Q3 + 1.5 × IQR. Values beyond the whiskers are shown as individual outlier points.
